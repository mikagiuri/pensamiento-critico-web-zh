批判性地思考

就是在没有先看理由之前，既不接受、也不拒绝一个想法。
要理由：“为什么？”“你怎么知道的？”
给理由：“我相信它，因为……”
如果出现了更好的理由，就改变看法

第1部分 · 什么是批判性地思考

是什么，不是什么

不是

  • 什么都批评
  • 总是唱反调
  • 不信任任何人
  • 自以为比谁都聪明

是

  • 问一句“你怎么知道的？”
  • 先看理由，再做决定
  • 接受有充分依据的东西
  • 承认自己什么时候错了

第2部分 · 已解决的案例

案例1 · 一则广告

“这款洗发水能让头发的光泽度提高80%。”
  1. 他们要我相信什么？头发会亮得多。
  2. 他们给了我什么理由？一个数字：80%。
  3. 他们是怎么知道的？没有说。比什么多80%？是谁测量的？
  4. 结论：我缺少信息。我现在还不接受，但也不说它是假的。

案例2 · 一个同学

莱雷（Leire）说数学考试在星期四：老师说的时候，她记在了记事本上。
  1. 他们要我相信什么？考试在星期四。
  2. 他们给了我什么理由？老师说的时候她记下来了。
  3. 这是一个好理由吗？是的：她当时在场，而且当场就写下来了。
  4. 结论：我相信。批判性地思考，也包括接受有充分依据的东西。

案例3 · 一开始的那条消息

“明天不上课。是我表哥说的，他在WhatsApp群里看到的。”
  1. 是谁最先说的？我不知道：我表哥是读到的，不是亲眼看到的。
  2. 那个人是怎么知道的？我也不知道。
  3. 我可以在哪里核实？在学校网站上，或者问老师。
  4. 结论：在核实之前，我不相信。

陷阱案例 · 第2部分 · 已解决的案例

⚠ 总是唱反调的人

艾托尔（Aitor）吹牛说：“我是批判性地思考的：我对老师们总是唱反调。”

他是在批判性地思考吗？

  1. 看起来是这样：别人说什么，他都不信。
  2. 可是，他看每件事的理由了吗？没有：他还没听就先说“不”。
  3. 这是多疑，不是批判性思考。
  4. 结论：唱反调不是思考。思考是看理由，不管别人说什么。
