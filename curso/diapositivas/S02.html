事实的主张

说的是事物是什么样的。它不是真的就是假的，哪怕有时候很难核实。
例子：“古根海姆博物馆在毕尔巴鄂”
要靠观察世界来判断：观察、测量、查找来源
如果它是假的，它仍然是一个事实的主张
批判性思维 · 初中二年级6/17
第1部分 · 三种句子

喜好

说的是我喜欢什么、不喜欢什么。每个人都有自己的。
例子：“我特别喜欢古根海姆博物馆”
线索：“我喜欢”、“我觉得没意思”、“我特别喜欢”
喜好没什么好争论的：没有哪一个是正确的
批判性思维 · 初中二年级7/17
第1部分 · 三种句子

观点（价值判断）

说的是某件事是好的、公正的还是更好的，或者我们应该做什么。它要用理由来支持。
例子：“毕尔巴鄂应该多建一些博物馆”
线索：“这是公正的”、“这不对”、“应该”、“更好”
有些观点的理由比别的更好

案例1 · 一句混在一起的话

一个网络视频博主评价一款电子游戏说：“它是2023年出的，我特别喜欢，你应该马上买。”
  1. “它是2023年出的”：说的是事物是什么样的。这是一个事实。
  2. “我特别喜欢”：说的是他自己喜欢什么。这是一个喜好。
  3. “你应该买”：说的是该怎么做。这是一个观点，我可以要他给理由。
  4. 结论：一句话里可能同时混着这三种类型。必须把它们分开。

案例2 · 一个假的事实

凯文（Kevin）说：“毕尔巴鄂竞技队在阿诺埃塔球场踢球。”
  1. 它说的是事物是什么样的吗？是的：一支球队在哪里踢球。
  2. 我去核实：毕尔巴鄂竞技队在圣马梅斯球场踢球。阿诺埃塔是皇家社会队的球场。
  3. 所以这是一个事实的主张……但它是假的。
  4. 结论：“事实”不等于“真的”。它的意思是：要靠观察世界来判断。

陷阱案例 · 第2部分 · 已解决的案例

⚠ 这只是一种喜好吗？

“因为别人的出身而打他是不对的。”

它是一种喜好吗，就像“足球让我觉得没意思”？每个人有自己的吗？

  1. 它说的不是我自己喜欢什么：它说的是什么是对的、什么是错的。这是一个观点。
  2. 可是并不是所有的观点都一样有分量：这个观点有非常有力的理由。
  3. 它会伤害人，它不公正，而且没有人愿意别人这样对待自己。
  4. 结论：某件事是观点，不等于怎么都行。要用理由来讨论。

第3部分 · 常见的错误

要小心这些想法

不是这样

  • “事实就是真的东西”
  • “什么是对、什么是错，只是各人喜好的问题”
  • 怎么都行（相对主义）：“所有的想法都一样好”
  • 教条主义：“我的想法永远不会改变”

这样才对：批判性思考的人

  • 一个事实可以是真的，也可以是假的
  • 喜好没什么好争论的；观点则可以争论
  • 比较各种理由，如果有更好的，就改变想法
  • 尊重一个人，不等于不要理由就接受他的想法
