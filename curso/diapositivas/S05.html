第1部分 · 四条相信的路

我们的信念是从哪里来的？

有很多事，我们没有看它们的理由就相信了。有四条路：

  • 习惯：“一直都是这样做的”
  • 群体：“我们这一伙朋友都这么相信”
  • 权威：“一个重要的人说的”
  • 情绪：“我愿意相信它”或者“我害怕”
批判性思维 · 初中二年级6/15
第1部分 · 四条相信的路

这四条路，配上例子

路例子用来检查它的问题
习惯“就是这样做的，因为一直都是这样做的”有什么理由吗，还是只是习惯？
群体“那部剧特别烂：我所有的朋友都这么说”我自己看过吗？
权威“一个有几百万粉丝的网络视频博主这么说”他懂这方面的事吗？
情绪“那不是犯规：他是我们队的”如果是对方球队，我还会这么说吗？
批判性思维 · 初中二年级7/15
第1部分 · 四条相信的路

这些路总是不好的吗？

错误

  • “如果群体相信，它就是假的”
  • “永远不要听任何人的”
  • “情绪一点用也没有”

这样更好

  • 我们知道的差不多所有事，都是别人告诉我们的
  • 相信懂这方面的人是合理的
  • 情绪会提供信息：害怕会提醒我们有危险
  • 问题是从来不去检查它们

批判性思维 · 初中二年级9/15
第2部分 · 瘸腿的国王

故事（1）· 整个王宫都在瘸

从前有一位国王，他是个瘸子。他的大臣们为了讨他喜欢，开始瘸着走路。很快整个王宫都在瘸：大臣、卫兵、厨师……没有一个人是直着走路的。
  1. 他们为什么瘸着走？他们什么地方也不疼。
  2. 一开始，是为了讨好权威：国王。
  3. 后来，是因为大家都这样做：群体。最后就成了习惯。
  4. 结论：没有一个人有瘸着走的好理由。

第2部分 · 瘸腿的国王

故事（2）· 骑士

一位从外地来的骑士走了进来，他是直着走路的。所有人都笑了。国王生气了。骑士说：“陛下，我两只脚同时在瘸。”
  1. 他们为什么笑？因为他和群体不一样，而不是因为他做错了什么。
  2. 这里起作用的是情绪：嘲笑，还有怕丢脸。
  3. 他的回答很机智：既嘲笑了这个习惯，又躲过了惩罚。
  4. 结论：唯一走得对的人，反而看起来像怪人。正常的，不一定就是合理的。

今天的案例 · 一种祛痘膏

迈伦（Maialen）相信一种祛痘膏有效。她那一伙朋友都在用，她最喜欢的网红在做广告，而且她自己也特别期待。
  1. “她那一伙朋友都在用”：群体这条路。
  2. “她最喜欢的网红在做广告”：权威这条路。可是，他懂皮肤吗？
  3. “她自己特别期待”：情绪这条路。
  4. 结论：这些都没有说明这种膏有没有效。最好去问懂的人：医生或者药剂师。

陷阱案例 · 第2部分 · 瘸腿的国王

⚠ 权威 = 不好的理由吗？

陈（Chen）相信地球绕着太阳转。他从来没有验证过：是他的老师给他讲的。

他是因为权威才相信的……那么，这是一个不好的理由吗？

  1. 是的，这是权威这条路。
  2. 可是老师懂这方面的事，而且科学已经验证过很多很多次了。
  3. 这和那个祛痘膏的网红不一样：他不懂皮肤。
  4. 结论：问题不在于相信别人，而在于相信不懂的人。
