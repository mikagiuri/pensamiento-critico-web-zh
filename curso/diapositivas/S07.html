第1部分 · 论证的组成部分

论证

论证，就是由一个或几个前提来支持的一个结论。
结论：我想让你接受的东西
前提：我为了让你接受而给出的理由
前提 = 理由，只是一个更专业的名称
批判性思维 · 初中二年级6/16
第1部分 · 论证的组成部分

标志词

标志词是提示用的词：它们告诉我们每个部分是什么。

  • 在前提之前：“因为”、“由于”、“既然”、“鉴于”
  • 在结论之前：“因此”、“所以”、“这就是为什么”、“于是”
  • 有时候没有标志词：要想一想什么在支持什么
  • 注意：“因为”有时解释的是原因，而不是给出理由

第1部分 · 论证的组成部分

它是论证吗？

不是论证

  • 单独的一个命令：“闭嘴！”
  • 没有理由的观点：“足球是最棒的”
  • 一个问题：“你来看电影吗？”
  • 零散的数据，没有结论

是论证

  • 有一个想要证明的东西：结论
  • 至少有一个支持它的理由：一个前提
  • “今天去看电影吧：这部电影明天就下映了”

案例1 · 结论放在前面

“我们得马上出发，因为比赛六点开始，而地铁要二十分钟。”
  1. 我找标志词：“因为”。它后面的是前提。
  2. 前提：比赛六点开始；地铁要二十分钟。
  3. 它前面的，是说话的人想让我接受的东西：我们得马上出发。
  4. 结论：结论不一定放在最后。关键是什么在支持什么。

案例2 · 没有标志词

“那个账号是昨天才注册的，而且没有说明图片是从哪里来的。那个视频可能是假的。”
  1. 没有“因为”，也没有“所以”。我问自己：它想让我接受什么？
  2. 那个视频可能是假的：这就是结论。
  3. 有什么东西来支持它？这个账号是新的，也没说图片是从哪里来的：这些就是前提。
  4. 结论：没有标志词时，我就问“什么支持什么？”。

案例 3 · 是论证吗？

“大周节（Aste Nagusia）在八月。有 txosna 小酒棚、音乐会和烟花。”
  1. 他有没有想让我接受的东西？没有：他只是在讲一些事情。
  2. 有没有哪句话在支持另一句？没有：只是零散的信息。
  3. 结论：这不是论证，是描述。

陷阱案例 · 第2部分 · 已解决的案例

⚠ 不是前提的“因为”

一个女孩走进教室，浑身湿透。一个男孩问她发生了什么事。这个女孩说：“我浑身湿透了，因为我被暴风雨淋到了。”

句子里有“因为”。它是论证吗？前提是什么？

  1. 这个男孩已经看到她湿透了：不需要说服他相信这一点。
  2. 这个女孩不想让他接受什么：她是在解释为什么会这样。
  3. 这个“因为”给出的是原因，不是相信某件事的理由。
  4. 结论：这不是论证，是解释。标志词有帮助，但还是要动脑思考。
