重构

重构论证就是把它有条理地写出来：前提在上，结论在下。
P1、P2…… = 前提
用一条横线把它们隔开
C = 结论
批判性思维 · 初中二年级6/17
第1部分 · 把论证整理有序

重构的四个步骤

  • 1. 找结论：他想让我接受什么？
  • 2. 找前提：他拿什么来支持它？
  • 3. 去掉多余的部分：装饰的话、重复、侮辱
  • 4. 问问缺了什么：有没有隐藏前提？
批判性思维 · 初中二年级7/17
第1部分 · 把论证整理有序

隐藏前提

隐藏前提是一个没有说出来的理由，但要得出结论又必须有它。
它也叫隐含前提
问：“要让这个论证成立，什么必须是真的？”
有时它正是最可疑的部分

案例 1 · 去掉多余的部分

“哥们儿，说真的，明天把签好字的同意书带来，没有它他们不让你上春游的大巴，你是知道的。”
  1. 他想让我接受什么？明天要带同意书：这是C。
  2. 他拿什么来支持？没有同意书，就不让上大巴：这是P1。
  3. “哥们儿”“说真的”和“你是知道的”是多余的：它们是装饰，不是理由。
  4. 结论：P1：没有同意书就上不了大巴。C：明天把同意书带来。

案例 2 · 戴眼镜的守门员

“一个男孩不可能当守门员：他戴眼镜。”
  1. C：一个男孩不可能当守门员。P1：他戴眼镜。
  2. 要得出 C，还缺什么？大概是：“戴眼镜的人不能当守门员。”
  3. 这就是隐藏前提。把它写出来，就能看出它是假的：可以戴运动眼镜或隐形眼镜来比赛。
  4. 结论：这个论证出问题，是因为那个没有说出来的前提。

案例 3 · 一个确实为真的隐藏前提

“今天没有训练：球场被水淹了。”
  1. C：今天没有训练。P1：球场被水淹了。
  2. 隐藏前提：“在被水淹的球场上不能训练。”
  3. 它是真的吗？是的，这很合理。这里的隐藏前提没有问题。
  4. 结论：找隐藏前提不是为了攻击别人，而是为了看论证站不站得住。

第3部分 · 公正地重构

重构别人的论证时

错误

  • 改变对方说的话
  • 加上谁也没想到的前提
  • 把侮辱当成理由留下来

这样更好

  • 尊重对方说的话
  • 只加上必须要加的
  • 去掉不是理由的部分

陷阱案例 · 第3部分 · 公正地重构

⚠ 我该选哪个隐藏前提？

“一个男孩不能骑他叔叔的摩托车：他才 13 岁。”

隐藏前提是“13 岁的人骑得不好”吗？那这个论证就不成立了，对吗？

  1. 这个前提会很可疑：不是所有 13 岁的人都会骑得不好。
  2. 但还有另一个前提也能得出 C，而且是真的：“法律不允许 13 岁骑摩托车。”
  3. 重构时，我选最合理的前提：说话的人会这样想的前提。
  4. 结论：如果你选最弱的前提，你攻击的就是一个没人提出过的论证。
