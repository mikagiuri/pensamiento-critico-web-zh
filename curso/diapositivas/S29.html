第1部分 · Asch：跟随群体（1951年）

这就是 Asch 的实验

一群人看着一条线，一个接一个大声说出另外三条（A、B 或 C）中哪一条和它一样长。这非常容易。
  1. 花招：除了一个人以外，所有人都是事先说好的演员。真正的参与者几乎是倒数第二个回答。
  2. 在有些轮次里，演员们故意给出同一个错误答案。
  3. 在这些轮次里，三个答案里有2个是对的。但三个里有1个跟着群体走了。
  4. 结论：大约四个人里有3个至少有一次让步；四个人里有1个，从来没有。有一个同伴的时候，几乎所有人都能坚持。

第2部分 · Milgram：服从权威（1961—1962年）

这就是 Milgram 的实验

Stanley Milgram 是美国耶鲁大学的心理学家，他对一些志愿者说，他在研究惩罚对记忆有什么影响。
  1. 志愿者是“老师”。“学生”被绑在另一个房间的椅子上，是一个演员。
  2. 每答错一次，老师就电击一次，电击一次比一次强。电击是假的，但他不知道。
  3. 演员抗议，敲墙，最后不再回答。如果老师犹豫，科学家就说：“请继续。”
  4. 结论：在最有名的版本里，有65%的人一直电击到最强的一档，450伏。

第2部分 · Milgram：服从权威（1961—1962年）

对 Milgram 实验的批评

  • 志愿者很痛苦：他们出汗，发抖，有些人还会紧张地大笑
  • 他们被欺骗了：不知道这到底是怎么回事
  • 很难停下来：科学家一再坚持
  • 今天，这样的实验，完整地做，是不被允许的

第2部分 · Milgram：服从权威（1961—1962年）

仍然有争论的地方

  • Milgram 做了很多版本：有的几乎没有人服从，有的几乎所有人都服从
  • 有些志愿者怀疑电击是不是真的
  • 当科学家说“你没有别的选择”时，很多人拒绝了
  • 也许很多人并不是盲目服从：他们认为自己是在帮助科学

陷阱案例 · 第3部分 · 我们学到什么

⚠ 消防演习

演习的警报响了。老师说：“排成队，走B楼梯。”所有人排队出去。一个女孩也是，没有争论。

他服从，并且和群体做一样的事……像 Asch 和 Milgram 那样吗？

  1. 是的：她服从了一个权威，并且和其他人做了一样的事。
  2. 但这个命令是合理的：老师知道疏散方案，而且他并没有要求伤害任何人。
  3. 在紧急情况下，对每个命令都争论是危险的。
  4. 结论：服从或者跟随群体本身并不坏。坏的是在被要求做错事的时候也这样做。
