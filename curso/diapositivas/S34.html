第1部分 · 核实的三个步骤

纵向阅读还是横向阅读

纵向（我留在里面）

  • 我因为设计好看就相信
  • 我读这个网站自己的“关于我们”
  • 我只看页面想让我看的东西

横向（我走到外面）

  • 我查别人怎么说这个网站
  • 我核对其他来源是不是说同样的事
  • 两分钟，我就知道得多得多

第1部分 · 核实的三个步骤

日期和图片的来源

  • 日期：一条旧新闻今天被转发，看起来像新的
  • 看它是什么时候发布的，不是你什么时候收到的
  • 图片：做一次反向搜索（例如用 Google Lens）
  • 它可以告诉你这张照片以前出现在哪里（不一定总能找到）

案例 1 · 无线网络的网站

这个专业的网站说学校的无线网络会伤害大脑。想象一下，你在另一个标签页里搜索它的名字。
  1. 横向阅读：你发现这个网站在卖“防电磁波”的设备。
  2. 卫生机构怎么说？他们没有发现正常水平的无线网络有什么危害。
  3. 这个网站有利益，而且与共识相反（第26课）。
  4. 结论：好看的设计不是理由。我不相信。

案例 2 · 雪

Dylan 收到：“比斯开省因为下雪停课！”下了一点雪，看起来像是真的。
  1. 看新闻的日期：是好几年前的。
  2. 今天有人又转发了它。
  3. 今天是教育部门或者学校这么说的吗？不是。
  4. 结论：是旧新闻，不是新的。明天上课。

案例 3 · 高速公路上的鲨鱼

在很多次大风暴之后，同一张照片都在流传：一条鲨鱼在被淹的高速公路上游。
  1. 我对这张图片做一次反向搜索。
  2. 它在不同国家的风暴里出现过，已经有十多年了。
  3. 核查人员解释说这是合成的：鲨鱼来自另一张照片。
  4. 结论：假图片。反向搜索一分钟就能发现。

陷阱案例 · 第2部分 · 已解决的案例

⚠ 什么也找不到的搜索

Chen 对一张毕尔巴鄂游行的照片做了反向搜索。在别的任何地方都没有出现。“那它就是真的，而且是今天的。”他想。

如果它以前没有在互联网上出现过，就证明它是真的吗？

  1. 反向搜索只能找到已经在互联网上的照片。
  2. 一张新的、裁剪过的或者用人工智能做的照片，可能搜不出来。
  3. 什么也找不到，什么也证明不了：既不能证明是真的，也不能证明是假的。
  4. 结论：核实不一定总有答案。有时诚实的做法是“我还不知道”，然后等一等。
