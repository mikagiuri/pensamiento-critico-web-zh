第1部分 · 零散的数字

百分比

百分比说的是每100个里有多少。25 %的意思是每100个里有25个。
50 % = 一半
25 % = 四分之一
100 % = 全部
它永远是某个东西的百分比

第1部分 · 零散的数字

绝对数和相对数

绝对数说的是有多少。相对数是和总数比较，例如用百分比表示。
绝对数：有30个学生及格
相对数：60 %的人及格（50个里有30个）
两个都需要，才能理解清楚

案例1 · 滑板车

开头的那个标题：“街区的滑板车事故增加了100 %！”（编造的例子。）
  1. 增加100 %是什么意思？就是现在是以前的两倍。
  2. 是多少的两倍？我看数据：去年有2起事故，今年有4起。
  3. 多了2起事故。这很重要，但数字这么小，算不上事故潮。
  4. 结论：不给出起始数字的百分比，可能会无缘无故吓到人。我要问“是多少里的？”。

案例2 · 酸奶

一则广告：“现在糖含量少了30 %。”（编造的例子。）
  1. 比什么少30 %？比以前的酸奶？还是比别的牌子？
  2. 假设以前有20克糖。少30 %就是14克。
  3. 对一小杯酸奶来说，14克还是相当多的糖。
  4. 结论：“更少”不等于“很少”。要看标签上的真实数字。

案例3 · 两个班

A班有20人及格。B班有15人及格。哪个班做得更好？（编造的例子。）
  1. 绝对数说明A班及格的人更多。
  2. 但我去问总人数：A班有40个学生，B班有20个。
  3. A班：40人中有20人 = 50 %。B班：20人中有15人 = 75 %。
  4. 结论：B班做得更好。要比较人数不同的群体，就需要相对数。

陷阱案例 · 第2部分 · 已解决的案例

⚠ 增加了10 %吗？

在一所中学里，英语及格率从40 %升到50 %。标题：“及格率上升10 %！”（编造的例子。）

50减40等于10。增加了10 %吗？

  1. 从40 %到50 %是10个百分点：就是两个百分比相减。
  2. 但按比例来看：在40的基础上多10，是四分之一。及格的人增加了25 %。
  3. 这两个数字都是真的，但说的是不同的事。标题把它们混在一起了。
  4. 结论：上升10个百分点不等于上升10 %。我要问：是百分点还是百分比？
