相关

当两个数据一起变化时，就有相关：一个上升时，另一个也上升（或下降）。
因果：一件事产生另一件事
单独的相关只是一个线索，不是证据

四种可能的解释

如果A和B一起上升，可能是……

  • A导致B（有时是真的）
  • B导致A（反过来）
  • 第三个原因同时产生了这两者
  • 巧合：碰巧一致，但毫无关系

案例1 · 冰淇淋和溺水

在表格里，这两个数据一起上升。吃冰淇淋会让人溺水吗？
  1. A导致B？不：没有人会因为吃冰淇淋而溺水。
  2. B导致A？也不：溺水不会让冰淇淋卖得更多。
  3. 第三个原因：天气热。天热的时候，人们吃更多冰淇淋，也有更多人去游泳。
  4. 结论：有相关，但谁也不是谁的原因。共同的原因是夏天的炎热。

案例2 · 手机和成绩

一项（编造的）研究发现，晚上手机用得更多的学生，成绩更差。
  1. 是手机导致了成绩差吗？有可能：它占掉了睡眠时间。
  2. 反过来呢？课上学得不好的人，也许会躲进手机里。
  3. 第三个原因呢？压力或家里的问题，可能同时造成这两件事。
  4. 结论：相关是一个线索。要知道原因，还需要更多研究。

案例3 · 纯属巧合

Tyler Vigen的网站发现，在美国，1999年到2009年间，在游泳池里溺水的人数，和尼古拉斯·凯奇（Nicolas Cage）的电影数量，起伏得一模一样。
  1. 尼古拉斯·凯奇的电影会让人溺水吗？当然不会。
  2. 有第三个原因吗？看不出有任何一个。
  3. 如果你比较成千上万个数据，有些会碰巧一致。
  4. 结论：两条一起变动的线，可能毫无关系。

陷阱案例 · 第2部分 · 已解决的案例

⚠ 烟草和癌症

吸烟的人得肺癌的病例，比不吸烟的人多得多。有人说：“相关不等于因果。这没有被证明。”

他说得对吗？我们不知道烟草会不会致癌吗？

  1. 单独一个相关确实不够。但在这里它不是单独的。
  2. 科学家排除了别的原因（年龄、工作……）。而且你吸得越多，风险越大；如果戒了，风险就会下降。
  3. 此外，他们知道它是怎么发生的：烟里有会损伤肺细胞的物质。
  4. 结论：当别的解释被排除之后，相关就能证明一个因果。这句话不是万能的借口。
