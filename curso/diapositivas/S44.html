案例1 · 偷斧头的人

一个中国的古老故事：一个农夫丢了斧头，怀疑是邻居的儿子偷的。那个男孩做的每一件事，他都觉得“像小偷”。后来他在自己的柴堆里找到了斧头。
  1. 农夫相信什么？相信那个男孩偷了他的斧头。
  2. 所以他把一切都往对自己想法有利的方向解释：走得快、微笑或不说话，在他看来都“像小偷”。
  3. 他在自己的柴堆里找到了斧头……那个男孩在他眼里又变得正常了。
  4. 结论：确认偏见。男孩没有变：变的是农夫的眼光。

案例2 · 上网搜索

一个男孩认为能量饮料帮他学习。他搜索：“能量饮料对学习的好处”。
  1. 这个搜索已经带着答案：它只要求好处。
  2. 他会找到证明他是对的网页，然后放心。
  3. 一个更公平的搜索是：“能量饮料和学习：优点和风险”。
  4. 结论：搜索时的确认偏见。我们也要去找那些可能证明我们错了的东西。

案例3 · 2-4-6任务

彼得·沃森（Peter Wason）的实验（1960年）：“2-4-6这组数符合一条秘密规则。你提出别的数列，我告诉你它们是否符合这条规则。”
  1. 很多人试8-10-12、20-22-24……全都符合。“规则是加2！”
  2. 但规则更简单：“三个越来越大的数”。
  3. 很少有人试那些有可能出错的数列，比如6-4-2或1-5-100。
  4. 结论：我们去找能证实自己想法的例子。更好的做法是去找反例，就像在第11课里那样。

陷阱案例 · 第2部分 · 已解决的案例

⚠ 是固执还是消息灵通？

一个男孩认为抽烟对健康有害。他看到一段没有任何来源的视频，说的恰恰相反。他不理它。

他只接受证明他是对的东西……这是确认偏见吗？

  1. 看起来是的：他拒绝了证明他错了的东西。
  2. 但他看了证据：他的想法背后有成千上万项研究；而那段视频没有任何来源。
  3. 偏见是仅仅因为一个证据说我错了，就更差地对待它。在这里，这个证据是差的。
  4. 结论：不因为一个糟糕的理由改变看法，不是偏见。无视一个好证据才是。

对确认偏见的四个刹车

  • 问问自己：“什么会让我改变看法？”
  • 有意去找说法相反的东西
  • 把做对的和做错的都记下来
  • 倾听想法不同的人，不要提前准备好回应
