案例1 · 一个女孩的一个半小时

一个女孩睡前打开抖音“看一会儿”，结果待了一个半小时。她并没有决定留下来：只是没有停下来。
  1. 无限滚动：始终没有出现结尾，没有一个自然的停下来的时机。
  2. 可变奖励：下一个视频可能特别好看。
  3. 这个女孩决定了打开应用，但没有决定待这么久。
  4. 结论：这种设计让她很容易继续、很难停下。刹车：开始之前先设定时间限制。

案例2 · 一个男孩的卡包

一个男孩玩一款足球电子游戏。他用真钱买球员卡包。一个月里，他花了60欧元，想抽到一个一直抽不到的球员。（虚构的。）
  1. 卡包就是战利品箱：他不知道会抽到什么就要付钱。
  2. 可变奖励：“下一个卡包可能就是好的”。
  3. 它很像赌博：你投钱，由运气决定奖品。
  4. 结论：游戏卖给他的不是一个球员，而是希望。刹车：设定花钱上限（或者一分不花）。

陷阱案例 · 第2部分 · 已解决的案例

⚠ 所有让人入迷的东西都是把戏吗？

一个男孩在读一本悬疑小说。每一章都在悬念中结束，他很难放下：一直读到十一点。

他入了迷、很难停下……这和无限滚动是一回事吗？

  1. 看起来一样：他入了迷，不想停。
  2. 但书不会盯着他，不会给他发提醒，而且它有结尾。
  3. 特别享受一件事并不是坏事。问题是一种夺走你停下来的时机的设计。
  4. 结论：问题不是“它让人入迷吗？”，而是“什么时候停是我自己决定吗？”而且睡觉也算数。
