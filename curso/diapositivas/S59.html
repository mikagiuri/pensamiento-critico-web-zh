第2部分 · 一步一步分析

第1步 · 他们要我相信什么

“一项研究证明VITAFOCUS能使记忆力提高40%。这是让你取得更好成绩的饮料。”
  1. 他们要我相信：如果我喝VITAFOCUS，我就能取得更好的成绩。
  2. 理由：“一项研究”。是真的吗？我无法核实：他们没有说是哪一项，也没有说是谁做的。
  3. 这够吗？记忆力更好不等于成绩更好。
  4. 结论：这个理由没有经过核实，而且也不足以推出这个结论。
批判性思维 · 初中二年级9/16
第2部分 · 一步一步分析

第2步 · 是谁说的

一位穿白大褂的著名油管博主推荐这款饮料。没有出现 #publi。
  1. 白大褂并不会让他成为专家：因此而相信他就是权威谬误（第27课）。
  2. 好感：我们喜欢他，于是放松了戒心（第50课）。
  3. 没有 #publi：可能是隐形广告（第51课）。
  4. 结论：他的意见不是证据，而且他可能是收了钱才说的。
批判性思维 · 初中二年级10/16
第2部分 · 一步一步分析

第3步 · 数字

“记忆力提高40%。”“10个学生里有9个已经在喝。”
  1. 比什么多40%？是怎么测量的？没有这些数据，这个数字什么也说明不了（第37课）。
  2. 10个里的9个是谁的？他们问了多少人？（第39课）
  3. 即使是真的，很多人在喝也不能证明它有效：诉诸大众（第28课）。
  4. 结论：数字听起来不错，但没有来源，也没有样本。
批判性思维 · 初中二年级11/16
第2部分 · 一步一步分析

第4步 · 把戏与结论

“仅限本周：买一送一。”此外，这则广告每天在手机上出现十次。
  1. 紧迫感：“仅限本周”，是为了不让我去比较。
  2. 看到十次并不会让它变成真的：重复只会让它变得熟悉。
  3. 它是说服还是操纵？是操纵：催促、名人，还有没有来源的数字。
  4. 结论：我没有理由相信它。睡好觉和好好学习才是有证据的。

陷阱案例 · 第3部分 · 小心别过头

⚠ 另一件白大褂，另一种情绪

虚构的宣传活动：一位急诊科女医生在医院里站在一个受伤的男孩旁边说话。“骑自行车要戴头盔：摔倒时保护你的头。”

情绪和白大褂，和 VITAFOCUS 一样。它也是在操纵吗？

  1. 它确实打动人，也出现了白大褂，和 VITAFOCUS 一样。
  2. 但她懂这方面的知识，而且研究表明头盔能减少头部受伤。
  3. 情绪陪伴着一个可以核实的理由；它没有取代理由（第16课）。
  4. 结论：情绪或权威本身并不是陷阱。要看下面有没有理由。
