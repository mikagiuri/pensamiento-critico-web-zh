案例1 · 球鞋广告

一个男孩穿着新球鞋走进教室，所有人都看着他。文字：“做被所有人注视的那个。学校里一半的人已经有了。”
  1. “做被所有人注视的那个”：憧憬式广告。它卖给你的是你将成为的样子，而不是球鞋。
  2. “学校里一半的人已经有了”：FOMO。它让你害怕被落下，就像归属感那样（第50课）。
  3. 如果我不买会怎么样？我的球鞋还能穿。这是一种欲望。
  4. 结论：广告把欲望伪装成了需要。想要它并不坏，但要清楚自己在买什么。

陷阱案例 · 第2部分 · 已解决的案例

⚠ 又一个被伪装的欲望？

一个男孩骑自行车摔倒了，他的手机坏了：开不了机。他训练完回来晚的时候，用它和家人联系。

“我需要另一部手机。”这是又一个伪装成需要的欲望吗？

  1. 看起来还是老样子：“我需要”常常其实是“我想要”。
  2. 但我来问关键问题：如果没有它，会怎么样？他没法通知家人。
  3. 这里有一个真正的需要：一部能用的手机。至于他是不是需要最贵的那款，则是另一回事。
  4. 结论：并不是所有的“我需要”都是花招。要一个一个情况去看，不能不假思索地贴标签。

狄德罗的睡袍

18世纪。法国哲学家德尼·狄德罗收到了一件礼物，一件很漂亮的新睡袍。他在一篇短文里讲了这件事：《告别我的旧睡袍》。
  1. 有了新睡袍，他觉得自己的旧草椅很难看。他把它换成了一把皮扶手椅。
  2. 后来他换了桌子、窗帘、画……整个书房都得和睡袍“相配”。
  3. 最后他变得更穷了，却没有更幸福。他写道：“我曾是旧睡袍的主人；我却成了新睡袍的奴隶。”
  4. 结论：一次购买可能带出另一次购买。今天我们把它叫做狄德罗效应。

象牙筷子

一个中国的传统故事。一位国王给自己做了一双象牙筷子（用大象牙齿做的、极其昂贵的材料）。他的大臣看到后，担心起来。
  1. “用了象牙筷子，他就不会想要泥碗：他会想要玉碗”，一种珍贵的宝石。
  2. “用了玉碗，他就会想要奢华的饭菜。然后是丝绸的衣服和宫殿。”
  3. 每一样奢侈品，都需要另一样与它相配的东西。这是一道阶梯。
  4. 结论：这和狄德罗的阶梯是同一道阶梯。第一级台阶看起来很小。

今天的狄德罗效应

买了一样东西，我们就会想要其他能和它“相配”的东西：

  • 新手机 → 手机壳、耳机、配套的手表
  • 新游戏机 → 另一个手柄、更多游戏、电竞椅
  • 毕尔巴鄂竞技的球衣 → 短裤、围巾、球袜
  • 刹车：我想要它本身，还是只是为了让它“相配”？
