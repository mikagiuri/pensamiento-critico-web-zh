案例1 · 一个女孩的卡片

一个女孩在一张卡片上写道：“13岁。毕尔巴鄂。我弹特里基蒂克萨。我很喜欢读书。我很害羞。”她的身份认同里出现了哪些因素？（编造的例子。）
  1. “13岁”和“毕尔巴鄂”：环境。它们是外部因素：她没有选择它们。
  2. “我弹特里基蒂克萨”和“我很喜欢读书”：一项能力和一个爱好。
  3. “我很害羞”：性格，一个内部因素。
  4. 结论：五条信息给了我们一些关于这个女孩的线索，但她远不止她的卡片。

案例2 · “我数学不好”

一个男孩数学考试没及格。那天下午他说：“我数学不好。我就是这样的，我不会改变。”
  1. 你怎么知道？这个男孩只有一次考试。
  2. 这是草率的概括（第19课）：从一个事例就跳到“总是”。
  3. 而且，能力是可以训练的：它不是一个固定的印记。
  4. 结论：“我这次考试没及格”是一个事实。“我数学不好”是他给自己贴的一个标签。

案例3 · 班上的搞笑大王

在班上，所有人都叫一个男孩“搞笑大王”。有一天他来了，神情严肃，一言不发。他们对他说：“你怎么了？你不是这样的。”
  1. 标签是概括一个人、却把几乎所有其他东西都落下的一个词。
  2. 这就像光环效应（第45课）：一个特点盖住了其他所有的东西。
  3. 这个男孩也可以难过，可以害怕，也可以认真地说话。
  4. 结论：“我”不是一个标签。一个人同时是很多东西。

陷阱案例 · 第2部分 · 已解决的案例

⚠ 是我自己选的

一个女孩说：“我最喜欢的音乐是我自己自由选择的。没有人影响过我。”

她的爱好完全是她自己选择的吗？

  1. 看起来是这样：没有人强迫她听任何东西。
  2. 但这些音乐她是在家里、在朋友圈里，以及在算法给她推荐的东西里听到的（第53课）。
  3. 这并不让它变假：它仍然是她的爱好，而且她决定怎么对待它。
  4. 结论：几乎没有什么是完全选择的，也几乎没有什么是完全强加的。几乎一切都是混合。
