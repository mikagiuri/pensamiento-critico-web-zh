它是你和一个你觉得自己属于的集体共有的东西：一个“我们”。
它回答的问题是：我和谁是“我们”？

案例1 · 同时有很多身份认同

我们回到这个男孩：来自圣图奇区、毕尔巴鄂竞技的球迷、说巴斯克语的人、哥哥、玩PlayStation的人、有一位加利西亚外婆的孙子。（编造的例子。）
  1. 个人的：他的性格、他的经历、他喜欢玩PlayStation。
  2. 集体的：毕尔巴鄂竞技、巴斯克语、街区、加利西亚的家人。
  3. 它们并不互相竞争：这个男孩可以觉得自己是毕尔巴鄂人，同时也爱着加利西亚。
  4. 结论：没有人只是一种东西。我们同时有好几种身份认同，而且它们和平共处。

案例2 · “他是皇家社会的”

一场德比之后，在班级的WhatsApp群里，有人写到一个男孩：“他是皇家社会的。千万别相信他。”
  1. 这个男孩被简化成了只有一个归属：他的球队。
  2. 这就是“我们和他们”（第66课）：因为是外人，就对外人更差。
  3. 这相关吗？是皇家社会的人，并不能说明这个男孩是不是可靠。
  4. 结论：把一个人简化成只属于一个集体是不公平的，还会为蔑视打开大门。

陷阱案例 · 第2部分 · 已解决的案例

⚠ 最好不属于任何集体

学完第66课之后，一个女孩想：“如果集体会造成‘我们和他们’，最好就不要觉得自己属于任何一个。”

不属于任何集体是个好主意吗？

  1. 看起来有道理：没有集体，就不会有对立。
  2. 但是归属能带来支持、陪伴和意义。我们每个人都需要它。
  3. 问题不在于有一个“我们”，而在于蔑视“他们”，或把他们简化成一件事。
  4. 结论：这是一个虚假的两难（第20课）。我们可以属于一些集体，同时善待外人。
