案例1 · 下午六点吃晚饭

Maialen 和家人去另一个国家旅行。那里的人下午六点吃晚饭。她爸爸评论说：“这些人真奇怪，这个点吃晚饭不正常。”
  1. 爸爸用自己的习惯去衡量别人的习惯：在巴斯克地区晚饭吃得晚。
  2. 对他们来说，奇怪的是我们：我们九点或十点才吃晚饭。
  3. 没有人会因为几点吃晚饭而受到伤害。这只是一种差异。
  4. 结论：这是民族中心主义。仅仅因为不是自己的习惯，就把不同的东西判断为奇怪。

案例2 · 门口的鞋子

回到一开始的案例：在陈的家里进门要脱鞋；在 Iker 家里不用。哪一家做得对？
  1. 这两家里有谁受到了伤害吗？没有。
  2. 每种习俗都有它的理由：清洁、舒适、尊重家。
  3. 合理的做法是去做客时留心观察并入乡随俗。
  4. 结论：没有哪一种更好。这是差异，不是错误。在这里，文化相对主义是适用的。

陷阱案例 · 第2部分 · 已解决的案例

⚠ “这是我们的传统”

在一个虚构的俱乐部里，新人第一天要被当众羞辱。老成员说：“这是我们的传统。如果你不尊重它，就是不尊重我们的文化。”

这是这个群体的习俗。必须尊重它吗？

  1. 看起来是这样：我们说过，不同的习俗是要尊重的。
  2. 但这里有人受到了伤害：新人被羞辱了。
  3. 尊重习俗是有界限的：每个人的尊严和人权。
  4. 结论：某件事是传统，并不能让它变好。我们可以带着理由去批评它。

第3部分 · 典型的错误

尊重一种文化

不是

  • 因为“这是他们的文化”就接受任何事
  • 认为一个国家的所有人都一样
  • 把我不了解的东西叫作“奇怪”

是

  • 先努力理解，再下判断
  • 看到每一个人，而不只是他的出身
  • 带着理由批评伤害别人的东西
